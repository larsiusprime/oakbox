Icons from [Noto Color Emoji](https://github.com/googlefonts/noto-emoji) (`2D/svg/`, commit e20cbc2), Apache 2.0 (see LICENSE). Placeholders until OAK box has its own imagery.

- `emoji_u26a0.svg`: warning (a callout, a step's unresolved issue)
- `emoji_u2705.svg`: check mark button (an issue resolved by a choice)
- `emoji_u274c.svg`: cross mark (an issue that blocks a run until it's dealt with)

`emoji_u2705.svg` and `emoji_u274c.svg` came from Google's Noto emoji CDN (`fonts.gstatic.com/s/e/notoemoji/latest/<code>/emoji.svg`), which serves the same SVGs: the files already here match it byte for byte.
