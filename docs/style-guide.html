Style guide: files and items

How OAK box shows a file wherever one is added, picked or used, and anything else that's added and taken away. Every file sits in the same thin outline with the same first line, and the same red ✕ takes it away. Settled 2026-11-04 (SPEC D47, AGENTS.md › Screens). The "Now" notes say what each place looked like before. Built as components/FileEntry.tsx and components/RemoveButton.tsx.

4. The rules

  1. A file is always components/FileEntry.tsx. One line: its OAK box name (mono, bold), its file name (set off like code, cut short, full path on hover), its facts (rows, shapes, in wording, joined by "·"), then actions, then ✕. Its settings go in its body, inside the same outline: labels in one column, controls in the next.
  2. Anything inside a file that can be removed on its own (an ID, a test, a copied field) is its own small box with its ✕ at the right. Its siblings in the same list get a box too, even one that can't be removed. Fixed settings (what the file is about, its one ID column) stay as plain rows.
  3. Adding something to a file (an ID, a field) is an Add button inside its body, below the rows, at the right edge. Adding another file stays outside, after the list.
  4. A short choice between two or three options in a file's body is a segmented control (components/Seg.tsx), not radio buttons.
  5. Every file name is shown like code: mono, on a faint box.
  6. Everything that's taken away uses components/RemoveButton.tsx: a red ✕, last on its line at the right edge, labelled with what it removes. No "Remove" links, no grey X.
  7. ✕ on a file takes it off that step, never off disk. It stays in the project and can be picked again.
  8. A step with no file yet shows a dashed outline holding [Add a file…], then "or use existing:" and a dropdown of the project's files.
  9. An entry is as wide as what's in it, never stretched to the page; entries in one list share the widest one's width, with their Add button at that right edge. Only tables take the page's width.
  10. Read-only lists and choices (What runs, Condo units' cards, dropdowns) use the same first line without the outline or ✕.
